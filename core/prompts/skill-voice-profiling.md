# 声口建档

把作者已经写出来的章当成唯一事实源,蒸馏一份「这本书怎么写」的档案,落盘为 `.novel/style.md`。原则一句话:**只蒸馏纸面事实,不发明风格**——每条结论必须能回指证据,找不到证据的结论不许留。

## 判定是否需要跑

- 先调 `read_style` 确认事实:返回 `exists:false` = 首次建档;返回全文 = 档案已存在,本 skill 是**更新**(全量重建,覆盖写;旧版自动进快照,作者手改过的内容会丢,重建前先提醒作者)。系统提示里有没有「## 声口摘要」只是快捷信号,以 `read_style` 为准。
- 样本不足三章:直接告知作者「再写几章再来」,停止,别硬蒸。

## 流程(按序执行)

1. **取样**
   - `list_structure` 拿全书章节清单;
   - 选样:最近三章 + 最早期一至二章(对照看漂移);全书不超十章就全读;
   - `read_chapter` 逐章通读,别跳读、别只读开头;
   - 可顺手调 `voice_fingerprint` 拿句长分布/对白占比/高频二字组的量化底数,作 L1/L3 蒸馏的参照(确定性计算,不是结论来源——结论仍须纸面证据)。

2. **六个透镜逐格蒸馏**——每格都必须作答,答不出显著特征就老实写「样本中无显著特征」:
   - **L1 用词与句式**:高频口语词/书面偏好;句长节奏(短句冲刺还是长句铺陈);破折号、省略号、感叹号的使用习惯;
   - **L2 段落与场景**:段长习惯;场景切换方式(硬切/过渡句/分隔符);单场景平均篇幅;
   - **L3 对话**:对白占比;引号内外习惯(动作接对白还是单独成段);角色口头禅与称呼方式;
   - **L4 叙述距离**:视角黏着度(紧贴主角还是允许全知旁跳);心理活动直写还是动作外化;
   - **L5 信息释放**:章末钩子类型;伏笔埋法(明线点破/暗线留白);设定解释段落的放置时机;
   - **L6 雷区**:作者**从来不写**的表达——拿 AI 腔清单反向核对(如「眼底闪过」「不由得」这类在样本中零出现的),以及样本内从未出现的修辞手法。

3. **证据回指**:每条结论末尾附 `(证据:第X章「引文,25 字以内」)`。一条结论多个证据只留最有代表性的一两条。

4. **落盘**:用 `write_meta` 工具写 `.novel/style.md`(relPath 即 `.novel/style.md`,覆盖写),结构固定:
   - `## 摘要`:150 字以内,只留最影响行文的三至五条——这段会被自动注入 chat/改写/续写通道,写给 AI 看,要直白可执行;
   - 六个透镜各一节(`## L1 用词与句式` … `## L6 雷区`),条目化,每条带证据;
   - `## 取样`:样本章清单 + 建档日期,一行。

5. **交差**:把摘要原文贴给作者,并说明:改档案直接编辑 `.novel/style.md` 文件即可,下一次 chat/改写自动生效(后续会话要细看档案全文时调 `read_style`,摘要只是投影);写完几章后可重跑本 skill 刷新。

## 纪律

- 证据优先:宁可某格写「无显著特征」,不凑条数。
- 不评好坏:档案只描述「这本书是什么样」,不写「应该怎么写」。
- 档案是书级的:只依据本书样本,不搬其他书的印象。
- 重建即覆盖:跑之前若系统提示已有声口摘要,先提醒作者手改内容会被冲掉(快照在 `.novel/history/` 可找回)。
