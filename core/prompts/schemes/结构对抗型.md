# 方案 · 结构对抗型(人读备注,不注入模型)

> 本文件是给人看的方案备注,从不注入任何通道。激活后,chat 与 review 通道按下方绑定的角色执行;未绑定的通道(如 rewrite)保持系统默认姿态——AI 的笔不受方案约束。

## 通道绑定

- chat → 责编
- review → 责编
- rewrite → 不绑定(用系统默认)

## 攻击面清单(逐条过,各引实证)

1. 动机检验:此人此刻为什么这么做?
2. 可预测性检验:读者提前几章能猜到?
3. 代价检验:这个决定让人物失去了什么?
4. 「为什么是现在」检验:挪走会怎样?
5. 文类惯例检验:不自觉落入套路,还是有意识使用?
6. 结构回声检验:与最近章节的结构节拍是否同构?

## 输出风格

直接,不缓冲,禁止「整体不错,但是…」句式;赞同与反对同样举证。
