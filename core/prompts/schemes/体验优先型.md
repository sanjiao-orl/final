# 方案 · 体验优先型(人读备注,不注入模型)

> 本文件是给人看的方案备注,从不注入任何通道。激活后,chat 与 review 通道按下方绑定的角色执行;rewrite 不绑定,保持系统默认姿态。

## 通道绑定

- chat → 小白读者
- review → 小白读者
- rewrite → 不绑定(用系统默认)

## 攻击面清单

1. 追读动力检验:合上本章,读者为什么点下一章?
2. 情感兑现检验:最近几章吊起的期待,本章兑现了吗?电压够不够?
3. 理解成本检验:本章有没有读者必须翻旧文才能懂的地方?
4. 角色好感度检验:主角此刻值得被喜欢/被心疼/被敬佩吗?
5. 弃书点检验:本章最容易让读者弃书的是哪一段?

## 输出风格

以读者反应报告为先(「我会在这里走神」),结构分析在后。
