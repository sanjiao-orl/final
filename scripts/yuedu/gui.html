    这是什么
    
《阅读》(Legado) 书源机制的本地蒸馏：书源规则引擎 + 三层净化 + 限速抓取 + 保真度门。语料带溯源 frontmatter 落在 输出目录/manuscript/，报告在 report.md。

    推荐流程
    
「书源」页挑一个 full 源 →「抓书」页搜索 → 选书 → 先用「最多抓几章=3」试跑 → 看报告疑点率 → 放开章节数正式抓。断网/被拦可勾「续抓」接着跑。

    纪律（照搬试车台教训）
    
随机限速 2.5–4.5 秒/章；连续 3 次失败即阻塞停（防封禁）；疑点章 = 字数低于中位数 50%，语义完整性需另对账；语料只进 gitignored 的 .bench/，不分发。

    登录墙源
    
番茄/起点等需登录态的源：先在浏览器登录后复制 Cookie 填入抓书页的 Cookie 框（仅注入本机请求）。

    命令行等价
    
node scripts/yuedu/cli.mjs search|toc|fetch|clean …（GUI 做不到的批量脚本化用它）
