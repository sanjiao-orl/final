# 块 4 试车台 · 建设初测（2026-08-28）

> 试车台批工作件：仪器建设记录 + 已得数字 + 阻塞项。测量报告（按 0017 §8 槽位组织）待语料齐后另件产出。

## 一、建成的仪器（全部脚本化、可重跑、不进 CI）

语料管道（scripts/fanqie-collect/）：
- `fetch.mjs`：番茄 SSR 采集（书页 __INITIAL_STATE__ + 目录 API + reader 页），限速/阻塞即停/断点续抓/单章失败跳过连续 5 章停。
- **字体混淆破解**：番茄正文约半数常用字替换为 PUA 码点，内嵌子集字体渲染；实测字体全站静态（dc027189e0ba4cd，跨书/跨章/跨 UA 同一文件），混淆集=300 常用汉字+0-9+a-z+A-Z。字体 cmap 只指向源字体 gid 不可程序反推，`render_font_sheet.py` 渲染 362 字形表 → 人工识读建 `font-map.json`（真实章节通读性验证通过，高频词抽查 自己/已经/我们 落点正常）。字体轮换时重建映射即可，管道不变。
- `decode.py`：raw json → 解码清洗 → 工作区 md（frontmatter 带 order/wordNumber/source）；截断残章按「CJK/官方 wordNumber < 0.5」过滤；`_decode-report.json` QA。
- `import-txt.mjs`（scripts/bench/）：本地 txt 导入器，UTF-8/GB18030 自动识别，「第 N 章/回/节」标题分章（不足 5 章按 4000 字定长切）——降级路径已备。

测量仪器（scripts/bench/）：
- `name-census.mjs`：确定性人名/称谓普查（零 LLM）。句首 CJK 连跑前缀计数为主抽取器（实测网文归属极简，「齐夏说」式归属近乎为零，主语态才是主场）+ 引号后归属 + 称谓后缀；词干吸收压噪；别名聚类（包含/编辑距离 1）+ 不一致嫌疑（低频形 vs 高频形）+ 前 20 名逐章分布。
- `perf-real.mjs`：真实语料跑 domain 确定性工具计时（子进程模式借 perf-benchmark）。
- `bench-pipeline.mjs`：全量管线。`summaries`（结构化摘要 → domain writeChapterSummary 真格式落盘）、`ledger`（逐章抽账本-worthy 事实 → upsertLedger 建仪器账本 + 角色动态变化落 character-dynamics.jsonl——现有四维无角色维，这是仪器⑤的观测面）、`metrics`（ledger_slice/chapter_slice 尺寸分布 + reconcile 耗时与命中）。
- `bench-probes.mjs`：`state`/`density`（零 LLM，分析仪器产物）+ `contradiction`（LLM 窗口跨章矛盾扫描，双锚）+ `continuation`（盖真章续写 vs 真章：voice.ts 确定性声口偏离 + LLM judge 情节/设定/声口三维打分）。
- `ledger-checkup.mjs`：真账本体检（仪器①完全体，只出脱敏统计：条目/字段填充率/锚点计数/git 史演变，正文不出本机）。
