# 块 4 试车台 · 测量报告（2026-08-30）

> 试车台批收口件：按 0017 §8 槽位组织的首批测量读数。口径基准日 2026-08-30（0828 定序后首份报告）；逐节带原始报告坐标（`.bench/reports/`），数字可复跑。**口径警示（全报告通用）**：LLM 通道为 OpenRouter 免费档 `minimax/minimax-m3:free`，非产品写作/审查模型——一切质量类读数只证「管线可测性 + 量级」，不下产品能力结论。

## 0. 语料与成本口径（0830 两批）

- **语料（现行口径）**：《诡秘之主》净本 v1.2——hetushu 通路 raw → 物化器（URL 去重 + 内容哈希去重 + 规则表清洗 + QA 门）产出 **1137 章 / 正文 465.1 万字符**。本批全部读数以净本为准；v0 口径（含 256 组翻页重复、3725 处水印的 1393 章物化本）降为历史对照，各节旧读数以「v0」标注。
- **两批 LLM 跑**：第一批（v0 语料，≈800 calls）＝本报告 v0 读数；**第二批（0830 下午，净本重跑，作者指令「按正确干净的文本重启 300 章测试」）**：摘要 300/300（422 calls）→ 账本 300/300（375 calls，含 2 章断点补跑）→ 矛盾扫描 60 窗（65 calls，零失败窗）→ 盖真章续写 5 点（10 calls）≈ **870 calls / 输入 ≈273 万 / 输出 ≈52 万 token**，单日免费档内完成。
- **净本两版修订（本批裁决环节新增发现）**：逐字核验引文时发现「URL 脚手架残段」水印家族——raw 全形混排水印 `www•ｈeｔusｈu•com.ｃoｍ` 被「站名裸串」规则洗掉站名半截后留下 `www•com.com` / `m•com•com` 等残段，**≈530 处、遍布 322 文件、大量插在人名/词中间**（「奥黛www•com•com丽」「重又m•com•com站起」）。v1.1 上跑的 LLM 批次携带此噪声（≈0.15% 字符量）。随即补规则「水印-站名全形+脚手架」（命中 **1614 次 = raw 全形水印真实总量**）重物化为 **v1.2**：规则残留 0，新增「CJK 夹拉丁残段」金丝雀仅报合法文本（TM/BOSS/BUG/DNA 等）；v1.1 全文稿存档 `.bench/work/净本-v1.1-manuscript-存档`。是否在 v1.2 上重跑 LLM 批次→§9。
- 零 LLM 仪器（name-census / perf-real / state / density / metrics）与 LLM 仪器（summaries / ledger / contradiction / continuation）全部可重跑、断点续跑。

### 语料质量修订（0830 裁决调研深查，修正全文口径）

裁决取证时发现两处系统性语料缺陷：

- **URL 重复**：目录翻页边界同页双抓——raw 1393 条含 **256 组重复 URL**（相邻 order 成对），唯一页 **1137**；物化器原未按 URL 去重，故前 300 章基线含约 38 对重复章（≈13%），573 万字符中约 113 万为重复拷贝。**无内容缺失**（1137 唯一页全部在案），纯冗余。物化器已修（URL 去重 + order 重排），**重新物化时点待作者决策（§9）**；「全本 1393 章/573 万字符」的历史口径相应修正为 **1137 章 / ≈460 万字符（去重后）**。
- **水印残留**：hetushu 中文名形态水印「和_图_书」（分隔符变体）**3725 处、覆盖全部 1393 个文件**，常插在句子中间（如「灵教团内部和-图-书皇室系」）；物化器原清洗只覆盖拉丁/全角形态，模式已补。
- **对读数的影响**：切片尺寸/耗时/对账读数量级有效（重复章均匀膨胀 ~13%），密度同向膨胀；**0018 对照实验必须在去重净本上重跑均匀基线**（对照公平性本就要求同语料），当前 300 章产物定位为 **v0 读数**。
- 失控实证扫描跑在含重复文本上：重复对逐字相同、不直接制造假矛盾，但 §4 各条「章号」为物化序（含重复展开），裁决引文以原章逐字核对为准（本次已做）。

## 1. 称谓不一致率（name-census，全本）

- **净本前后对照**：v0（含重复+水印）同口径 2359 对嫌疑 → 净本 **1735 对（-26%）**；克莱恩×7912 → ×6480（-18%，正是翻页重复的膨胀量）；克莱/克莱恩两形频次在 v1.2 完全对齐（脚手架残段插名如「奥黛www•com•com丽」造成的计数歪斜消除）。**语料清洗对确定性仪器读数的修正效应首次定量可见。**
- **仪器局限（已记档）**：聚类含功能词噪音（「这是/第一/就在」等被后缀包含规则过并），语义级归一明确归 LLM 探针（0017 §4 别名归一），确定性层只做候选池。

## 3. 真实规模性能曲线 → 索引层阈值（本报告最重的一节）

**规模**：账本 2.45MB / 300 章（净本 v1.2，v0 2.4MB——收紧提示词「每类≤3条」未降低账本体积，体积由 knowledge 累计主导；线性外推全书 ≈11MB）。

**切片尺寸（ledger-metrics，12 样本，净本口径）**：`ledger_slice` 平均 **44.0 万字符**、`ledger_chapter_slice` 平均 **49.2 万字符**（v0：43.2 万 / 41.4 万）——chapter 切片不再更小、反而更大，**全局累计项主导**（knowledge 的 knows 无限累加、promises 全量注册表）进一步坐实；且**双双超过任何模型上下文窗口**。

- 含义①：0011「注入预算上限」与 0017「导生索引层」由设计要求升级为**实测生存条件**——不建索引/窗口化，第 300 章起账本不可注入。
- 含义②：chapter_slice 收敛失效说明尺寸被**全局累积项**主导（knowledge 的 knows 无限累加、promises 全量注册表）——这正是 0017 信封「区间」语义的价值位点：切片必须按区间裁剪，而非按章过滤。
- **耗时侧反而无碍**：full slice ≈812ms、chapter_slice ≈759ms、reconcile 2089ms/300 章（净本；v0 668/644/1553ms）——查询代价不构成瓶颈，**瓶颈全在注入尺寸**。0017 §8 ②「信封查询代价 vs 异构」的天平因此明确倒向「信封+索引层」。

**确定性工具全本计时（perf-real，净本 v1.2 全本 1137 章；v0 括号内为 1393 章旧读数）**：scan_quality 1326ms（RSS 峰值 270MB；v0 1606ms/290MB）/ word_count 337ms / search_content 10ms（v0 230ms——本批给 perf-real 补了 `--query` 参数，v0 硬编码「齐夏」在诡秘语料近乎空查，该格两批均不可比，仅列存疑）/ diagnostics 739ms（RSS 峰值 265MB；v0 1170ms/316MB）。语料缩 20%（去重+去水印）后耗时与内存同向回落，**确定性诊断路径在全本规模可用**的结论不变；内存峰值 ~300MB 需进入子进程模式常态化（现行架构已如此）。

**索引层阈值建议（喂 0017 §3 触发条件）**：以「切片 ≤ 上下文预算（如 3 万字符）」反推，账本在 ~20 章规模即超限——索引层不是 4.6 的可选项，是 4.1 的伴随品。数字挂 4.6 触发的原始设定应改为「4.1 起必须存在最小索引层」。

## 4. 失控实证目录（probe-contradiction）

**净本 v1.2 重跑（0830 第二批，加强提示词）**：前 300 章 60 窗全报、零失败窗，候选 **11 条**（0.18 条/窗；v0 同故事跨度的 300 章窗口为 24 条）。置信：高 0 / 中 2 / 低 8 / 自撤 1。加强内容＝把附录 A 裁决发现的失败模式回灌提示词：①quote 必须逐字摘抄；②同场景多物/多人不算矛盾；③「提前/已经/再次」类预设词先核前文前提；④时间推进/知情差异/言语不实可解的先自解，**强制输出 excluded（报前已排除的合理解释）字段**。

- **裁决（附录 B，逐字取证 + Wiki 外锚）**：11 条全部为误报或自撤，**0 真矛盾**。新失败模式实证：#4 疑问句（「难道特里斯变成了女性？」——克莱恩的推测恰是剧情真相，Wiki 锚定特里斯序列7女巫变性为特莉丝）被当断言报出且 excluded=无；#9 为生成中自我推翻的「自撤条目」（desc 三次改口后自判「未发现双锚齐全的矛盾」，未给引文）——excluded 纪律在输出层真实生效。
- **召回代价（必记）**：v0 唯一坐实的真矛盾「守门人浅蓝→灰蓝」（同章 6 行间距两写）在净本 166 章 L195/L201 **原样存在**，本批探针**未复报**——判别纪律收紧的同时吞掉了已知正样本。结论：窗口级 LLM 扫描的精度/召回天平对提示词措辞高度敏感，**单一采样不可靠**；0018 分层导入应在章节簇层补「同章确定性一致性检查」（同实体+颜色/数量词邻近共现，成本近零），LLM 探针退居复核位。
- **引文锚定（净本口径）**：20 条引文（10 双锚）逐字核验——去标点宽松口径 16 逐字 + 2 头部片段 = **90% 锚定**，2 条系模型自述非原文（与 v0 reconcile 门 81.6% 可用率同向）；严格逐字节口径 80%（模型保留原字但归一了标点）。

## 5. 盖真章续写对比（北极星首次可测，裸上下文口径）

- **逐点**：50章 2/3/2、120章 2/4/2、200章 2/2/3、280章 1/2/2、300章 2/1/2（plotFit/canonClash/voiceFit）。judge 一句话理由均指同一类失败：**情节走向凭空分叉**（场景偷换、捏造入场、设定序列错位），而非文风崩坏。
- **v0 结论降级**：v0 曾观察到「plotFit 随深度单调上升（1→3）」，第二批同点位未复现（2/2/2/1/2）——5 点位 × 单次采样的方差足以淹没该趋势，**该结论从报告撤回**，留待更多点位或多样本均值。
- **此为北极星对照基线**：块 4 注入成型后同点位复测，差值即注入价值的首次直接读数。
