# 块 4 · 4.0+ 对照实验（分层导入 vs 均匀深读）

> 依据：`docs/reference/05-账本与长篇连续性.md`（批序 4.0+）与 `06-完本书分层导入与事件骨架.md`（对照设计§对照判据）。脚本=`scripts/bench/layered-pipeline.mjs`；通道=OpenRouter `minimax/minimax-m3:free`（试车台批同款同档，两臂同模型保公平）；产物全部 gitignored（`.bench/`）。

## 对照设计（0905 落地决策记档）

- **同台口径**：同一净本 v1.2 前 300 章、同一摘要缓存（两臂共用）、L3/抽查与基线臂**同一抽取提示词**（EXTRACT_SHAPE+稀疏预算 system，bench-pipeline 同款）。
- **臂隔离**：分层臂独立工作区 `.bench/work/诡秘之主-净本-分层`（setup 复制正文+摘要，基线臂零接触）。
- **分层管线**：L1 簇纲要（25 章/簇×12，1 call/簇）→ L2 两章一段平铺（150 段，1 call/段，粗层不产锚）→ 对撞互认领（12 簇，orphan/hollow 疑点）→ 确定性注意力排序（层级权重×承重代理×疑点簇加成）→ L3 需求驱动精读**选章 40%**（120 章，同基线提示词写分层账本）→ 分层抽查 30 章（偏重未精读区 20:10，地面真值 JSONL）。
- **预算**：12+150+12+120+30 ≈ 324 calls（重试余量后 ≈380）< 600 上限。
- **判据**（reference/06）：召回损失与成本节省的交换比 + 失控检出率不降（实锤 4 条必须检出——**范围修正记档**：辛西娅 622-624 / 乌特拉夫斯基全书 / 安德森窗口>300 三条在 300 章范围外，不作检出要求；范围内守门人 166 必须被同章确定性一致性检查捕获）。
- **通道排障记档**：opencode zen deepseek-v4-flash 余额不足、nemotron-3-ultra-free 连接超时（TLS 断）——撞墙两次即停排查，改走 OpenRouter 免费档（试车台同款），对照公平性反而更优。

## 过程读数

- **L1 纲要**：12/12 簇 ✅，骨架事件 155 条（calls=12, in 60.9k / out 12.7k tokens）。
- **L2 平铺**：150/150 段 ✅，平铺事件 1189 条（calls=184 含重试, in 840k / out 104k）。
- **对撞**：12/12 簇 ✅，orphan（自底无容器认领）53 条、hollow（自顶空心容器）5 个、疑点簇 4/12（calls 累计≈25 含三次通道病排障，见下）。
- **通道病与修复（工程记档）**：免费档在长 JSON 输出中字符串值内未转义 ASCII 引号（`晋升"无面人"`、`""世界"登场`），genJSON 首尾大括号解析阵亡——lib.mjs 新增 `repairInnerQuotes` 状态机修复（串内 `"` 后随非结构符即转全角），修复后对撞全过。此项为免费档通道的普适加固，非分层管线专属。
- **rank**：事件 1344 条参与注意力排序；L3 选章 120/300（40%）。
- **L3**：120/120 选章 ✅（calls=130 含重试, in 339k / out 152k）。
- **抽查**：30/30 章 ✅（calls=32），地面真值 725 事实（偏重未精读区 20:10）。
- **总成本 ≈383 calls**（L1 12 + L2 184 + 对撞≈25 含排障 + L3 130 + 抽查 32），免费档单日，预算内。

**重大附带发现（比对照结果本身更承重）**：同一提示词对同一章的两次独立抽取，章锚定重合率仅约 8-30%（基线臂对自己抽查章的"自召回"也只有 7.6%）——**免费档抽取的跨运行稳定性极低，召回对比被噪声主导**。结论：召回损失数值本批不可判；根治依赖 4.1 提案机器（操作序列+实体归一+锚级对账）——本实验等于提前给 4.1 的断言清单供了一个实证理由。

**实现缺口记档**（脚本已修，复跑可补）：分层臂 L3 角色动态未落盘（bench-pipeline 有 character-dynamics JSONL，本脚本首跑漏了），角色维不可比；对照判据的召回维度受此+噪声双重限制。

**判据裁决建议（呈作者）**：成本（深调用-65%、全本外推-50%）✅；失控检出率不降（确定性捕获>LLM 漏报）✅；精度占优 ✅；召回不可判（噪声主导，挂 4.1 补测）。→ **建议分层路线有条件通过**：0018 主体实施挂 4.1 之后按提案机器对账补测召回再终裁；被否选项⑤（维持均匀深读）不复活。若作者认否，退回条件也已带数（本表即退回依据）。
