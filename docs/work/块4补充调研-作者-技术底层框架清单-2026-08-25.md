# 块 4 补充调研（作者轮）· 技术底层框架清单（2026-08-25）

> 作者补充调研原件（桌面文档拷贝归档，内容未改动）。起因与定位同 HITL 全景件：块 4.0/决策 0017 的补充输入，覆盖前三线未扫的基础设施层；三问过滤与落位见 `docs/work/块4长篇连续性调研-2026-08-24.md` 交叉审记与 0017。

简介：在 AI 驱动的长篇叙事、复杂世界观管理（设定集、人物关系、物品归属、时间线）与深度角色扮演（RP）领域，上层应用确实缺乏成熟的“一键全自动写作”开源爆款；但底层技术栈已高度标准化并形成工业级基建。

本轮筛查排除了仅停留在概念期、缺乏维护或 Star 数极低的小众 Demo，严格从代码开源性、社区认可度（GitHub Stars/下载量）、技术先进性及与虚构世界状态管理的匹配度四个维度进行筛选，整理出一份可靠的技术底层框架清单。

目录：

- 时态知识图谱与动态记忆层（管理网状人物关系、世界观演化与时间线有效性）
- 模式约束与状态增量引擎（杜绝属性数值漂移、背包物品幻觉与死亡状态错乱）
- 状态机、事件流与剧情流转引擎（管理三幕式节拍、分支回溯与长任务持久化）
- 角色认知与交互式叙事编排框架（实现拟人化长线交互与多模块装配）
- 技术选型与架构拼装建议

## 一、时态知识图谱与动态记忆层

针对世界观中“设定不是静态的，而是随剧情推进动态变化”的特性，传统向量检索（Vector RAG）无法识别时间先后与实体关系，时态图谱（Temporal Graph）是当前的最优解。

1. Graphiti
   - 项目出处：getzep/graphiti（由 AI 记忆系统研发团队 Zep 开源维护）
   - 开源协议：Apache-2.0
   - 认可度与状态：活跃维护中，专为 AI Agent 实时构建动态上下文图谱而设计。
   - 核心机制与适用性：
     - 时间有效性窗口（Validity Windows）：为图谱中的关系边增加 valid_from 和 valid_to 元数据，能够明确记录“A 在第 1~5 章持有神器 X，第 6 章神器被摧毁”，当检索当前状态时会自动忽略已失效关系。
     - 混合检索：结合向量相似度、关键词搜索与多跳图遍历，适合处理跨人物、跨势力的复杂因果关联。

2. Microsoft GraphRAG
   - 项目出处：microsoft/graphrag（微软研究院 Microsoft Research 团队）
   - 开源协议：MIT
   - 认可度与状态：GitHub 35,000+ Stars，业界公认的知识图谱增强检索标杆。
   - 核心机制与适用性：
     - 层次化社区聚类（Hierarchical Leiden Clustering）：从非结构化设定集或历史正文中提取实体，并自底向上构建多层级社区摘要。
     - 宏观设定理解：擅长回答全局性、全书视角的设定查询（例如“整个大陆各宗门在过去百年间的敌对关系演变”）。

3. Cognee
   - 项目出处：topoteretes/cognee（专为 AI Agent 设计的认知记忆平台）
   - 开源协议：Apache-2.0
   - 认可度与状态：专为多会话持久记忆和本体推理构建，支持 MCP（Model Context Protocol）协议接入。
   - 核心机制与适用性：
     - 将文本转化为结构化的本体图（Ontology），支持数据写入后的认知提炼（Cognify 管道）。
     - 自动在会话缓存与长期图谱间路由查询，适合维护角色对玩家的长期认知与世界常识。

4. Mem0
   - 项目出处：mem0ai/mem0（原 Embedchain 团队演进）
   - 开源协议：Apache-2.0
   - 认可度与状态：GitHub 40,000+ Stars，目前最流行的通用 Agent 记忆层中间件之一。
   - 核心机制与适用性：
     - 提供自适应的实体记忆抽取与更新 API，能够自动合并冲突事实，适合轻量级挂载在角色卡背后维护人物动态偏好与历史事件。

## 二、模式约束与状态增量引擎

大模型直接输出文本极易产生“死人复活”、“物品凭空消失/出现”等逻辑幻觉。该层负责从模型端强制提取确定性的状态更新差量（State Diff）。

1. Instructor
   - 项目出处：jxnl/instructor（由著名开源开发者 Jason Liu 创立）
   - 开源协议：MIT
   - 认可度与状态：GitHub 13,000+ Stars，Python/JS 生态中基于 Pydantic 的结构化输出事实标准。
   - 核心机制与适用性：
     - 在大模型生成前后增加验证器（Validators）与自动重试（Retries）。
     - 强制模型输出符合特定模式（Schema）的 JSON 状态补丁（如：HP 变化量、物品所有权转移、地理坐标移动），校验不通过时自动引导模型修正。

2. Outlines
   - 项目出处：dottxt-ai/outlines（由 .txt 团队开发维护）
   - 开源协议：Apache-2.0
   - 认可度与状态：GitHub 15,000+ Stars，本地推理与引导式生成的领先库。
   - 核心机制与适用性：
     - 引导式解码（Constrained Decoding）：直接介入大模型推理时的 Token 采样概率，利用正则表达式与有限状态机（FSM）拦截非法 Token，从底层保证输出 100% 符合 JSON/SQL 格式，杜绝格式崩溃。

3. BAML (Boundary Structured Prompting)
   - 项目出处：BoundaryML/baml（专为 AI 结构化输出设计的专用领域语言）
   - 开源协议：Apache-2.0
   - 认可度与状态：GitHub 8,000+ Stars，在复杂 Schema 解析与流式结构化输出领域增速极快。
   - 核心机制与适用性：
     - 提供了类型安全的独立 DSL，支持在生成过程中以流式（Streaming）方式逐字段解析复杂嵌套的角色与事件结构，降低开发维护成本。

## 三、状态机、事件流与剧情流转引擎

负责管理叙事节奏（如三幕式节拍）、分支剧情流转、长周期任务状态持久化与剧情回溯（Undo/分支线）。

1. LangGraph
   - 项目出处：langchain-ai/langgraph（LangChain 官方团队开发）
   - 开源协议：MIT
   - 认可度与状态：业界构建有状态循环多智能体系统的核心引擎。
   - 核心机制与适用性：
     - 状态图与检查点机制（Checkpoints & Time-travel）：将创作流程定义为带状态的图（大纲制定→场景草稿→冲突审查→状态提交）。
     - 支持任意步骤的断点回溯与分支演绎，非常适合创作者对某一章节不满意时进行局部回滚和重构。

2. Temporal
   - 项目出处：temporalio/temporal（前 Uber 架构团队创立，Temporal.io 维护）
   - 开源协议：MIT
   - 认可度与状态：GitHub 22,000+ Stars，企业级分布式持久执行与事件溯源（Event Sourcing）的工业标准。
   - 核心机制与适用性：
     - 将每一次世界状态变更记录为不可变事件流（Event Log），系统即使崩溃或长时间暂停也能 100% 恢复当前状态。适合构建高可靠的常驻世界观模拟器与后台挂机 NPC 系统。

## 四、角色认知与交互式叙事编排框架

将上述底层状态与记忆组装为面向用户的角色扮演或协同叙事界面。

1. SillyTavern（酒馆）
   - 项目出处：SillyTavern/SillyTavern（开源社区自治维护）
   - 开源协议：AGPL-3.0
   - 认可度与状态：GitHub 10,000+ Stars，角色扮演（RP）与互动小说（CYOA）领域的标准前端。
   - 定位与适用性：
     - 虽脱胎于前 Agent 时代的 Prompt 拼装，但其深度集成了 World Info（世界观关键词/正则触发器）、Data Bank（向量库）、STScript 自动化脚本与多角色轮转机制，是目前验证角色人设与设定交互最方便的集成测试工作台。

2. Letta (原 MemGPT)
   - 项目出处：letta-ai/letta（UC Berkeley 论文《MemGPT》衍生平台）
   - 开源协议：Apache-2.0
   - 认可度与状态：GitHub 15,000+ Stars，状态化 Agent（Stateful Agents）的核心运行时。
   - 定位与适用性：
     - 将 Agent 建模为类似操作系统的内存架构（Core Memory、Recall Memory、Archival Memory），Agent 可以通过内置工具主动修改自身核心人设与记忆条目，适合构建能够自主演化认知的 NPC。

## 五、技术选型对照总览

| 目标层级 | 推荐项目 | 许可证 | 解决的核心问题 |
|---|---|---|---|
| 关系与时态演进 | Graphiti / Microsoft GraphRAG | Apache-2.0 / MIT | 解决人物关系动态变化（如背叛、结盟）与随时间推移的设定失效/覆盖问题。 |
| 属性与物品约束 | Instructor / Outlines | MIT / Apache-2.0 | 强制模型输出结构化 Diff（如血量增减、道具转移），数据库强校验杜绝逻辑幻觉。 |
| 剧情节奏与流程 | LangGraph | MIT | 管理三幕式故事节拍、分步骤多 Agent 流水线，支持状态回溯与人工介入（Human-in-the-loop）。 |
| 持久化与事件溯源 | Temporal | MIT | 记录不可变的事件流（Event Log），支撑超长周期世界观演变与无损状态复原。 |
| 交互与人设测试 | SillyTavern / Letta | AGPL-3.0 / Apache-2.0 | 提供可视化的多角色设定管理、长线记忆挂载与对话调试界面。 |
