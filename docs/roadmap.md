# 路线图（第三次出发）

> 裁决标准（北极星）：**作者用本软件写完 3 章可投稿水准的章节。** 不服务于此的工作默认降级或不做。
> 验收纪律：不读文档验收，用可执行检查单（测试复跑 / 功能实测 / 对照成熟基准）；每周末作者亲写验收是机械刹车。

## 第 1 周 · 建仓+核心链路（本仓当前位置）

- 仓库骨架、core（Node sidecar：AI SDK v7 + MCP client + node:sqlite 会话持久化 + 127.0.0.1 HTTP/SSE）、domain（MCP stdio 领域服务 v1 五工具）；
- 出口：浏览器裸联调 `/dev`，核心全链路**对话 → 工具 → 流式 → 重启恢复会话**跑通。

## 第 2 周 · 壳（Tauri 2 + Svelte 5 + TipTap）

- 三栏布局、`theme.ts` tokens、结构树（状态点+字数）、明暗切换、F8 专注、打字机滚动；
- 安全阀四件 Day-1：软删 `.novel/trash/`、保存显式报错、滚动快照 `.novel/history/`、全稿导出 txt；
- Tauri updater Day-1；SSE 直连 sidecar，token 30–50ms 批次进 store；
- 出口：**作者用新仓纯手写一节**。

## 第 3 周 · AI 交互

- 选区浮动条；内联删除线候选/侧栏 diff；暂存抽屉批量勾选（采纳/整改/丢弃）；AI 面板 + 两个讨论存区（无归属/章节内）；
- 出口：作者用新仓完成一次"讨论 → AI 改写 → 暂存区批量采纳"的完整循环。

## 第 4 周 · 理解层

- 从 novel-rl 搬 understanding 层（约 5,700 行 + 最厚测试），只接**一个出口**：一致性审阅清单（伏笔/时间线/口吻/知情权）；
- 出口：对一部测试书稿跑出作者可见的审阅报告。

## 明确不做

- 图形化世界观模块（地图/历法/关系图）、多人协作、模型市场、EPUB 排版、AI 绘图、设置面板、治理体系建设（规则/审计/双工具协议——永不再建）。

## 止损线

第 2 周壳可用后，若 **4–6 周内仍无动力用它写完一章** → 判定产品假设不成立，体面终止。可剥离资产：理解层、core sidecar、领域 MCP 工具集。
