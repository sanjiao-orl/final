# 协议契约

core 与壳/外部客户端之间的 HTTP + SSE 契约。本文件是**唯一契约文档**；数值与实现真相源在代码，本文件只描述形状，漂移由 `check:docs` 第 9 条机械拦截。

## 版本化

- 全部业务路由挂 `/v1/` 前缀；无 `/v1/` 前缀的路径一律 404，错误消息带迁移提示（判定在鉴权之前，`core/src/server.ts`）。
- 协议版本号**不手写**：真相源 `core/src/runtime.ts` `PROTOCOL_VERSION`；壳侧期望值钉在 `shell/src-tauri/src/lib.rs` 与 `shell/src/App.svelte` 的 `EXPECTED_PROTOCOL`，三处相等性由 check-docs 校验。前缀变了协议号必升，反之亦然。
- 变更纪律：协议字段/事件顺序/错误形状的任何变更必须升协议号并同步更新本文件。

## 接线与握手

- core 固定监听 `127.0.0.1:47832`（`lib.rs` `CORE_PORT`，dev/prod 两分支 spawn 均传 `--port`）；Bearer token 每次启动随机。
- 握手双通道同一组字段（`RuntimeInfo`：port/token/pid/startedAt/version/commit/protocol）：stdout ready 行（`{"event":"ready",...}`）+ `core-runtime.local.json` 自报文件（`core/src/runtime.ts`）。
- 壳按 ready 行/health 自报的 `protocol` 校验兼容性，不等于 EXPECTED_PROTOCOL 即拒接（`lib.rs` `validate_protocol`、`App.svelte`）。
- 端口绑定失败：core 向 stdout 打单行 `{"event":"fatal","message":"…"}` 后退出；壳 `watch_core` 识别 fatal 行，Starting→Failed 带具体原因。
- 例外：e2e / promptfoo 自拉 core 不传 `--port`，仍走随机端口（无 CSP 约束的进程间通道）。
- CSP（`shell/src-tauri/tauri.conf.json`）：生产 `csp` 的 connect-src 精确到 `http://127.0.0.1:47832`，无通配；`devCsp` 另放行 vite `localhost:1420`。两处事实源由 Rust 测试 `csp_pins_core_port` 钉死。

## 鉴权

除标注「免」外一律 `Authorization: Bearer <token>`（常量时间比较，`server.ts` `bearerTokenMatches`）。CORS：白名单 Origin 反射，其余不给 Allow-Origin。

## SSE 帧

- 所有 SSE 帧经唯一发射点 `core/src/event-pump.ts`：`event: <名>` + `data: <JSON>`，按发射序串行写出，`done`/`error` 必是最后一帧；带背压处理。
- 事件名按通道：`/v1/chat` = `text-delta` / `tool-call` / `tool-result` / `done` / `error`；`/v1/rewrite` 与 `/v1/continue` = `text-delta` / `done` / `error`。

## 候选模型（暂存区）

- 字段：id / sessionId / chapter / original（锚定原文）/ proposed / instruction / status / kind / created_at / updated_at（`core/src/candidate-store.ts`）。
- status 状态机：`pending → adopted | discarded`，已决策是终态，非法迁移 400；不物理删。
- kind 三态（创建后不可变）：`replace`（锚定替换，original 非空）/ `append`（追加章末）/ `replace_all`（整章替换，frontmatter 由壳保存时拼回）。
- chat 通道正文产出一律经 core 本地工具 `stage_chapter_proposal` 以 pending 候选进暂存区（只在流式 chat 请求内可见，不上 /v1/tools）；旧库缺 kind 列自动 ALTER 迁移。
