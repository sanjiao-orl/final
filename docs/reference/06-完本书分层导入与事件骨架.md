# 完本书分层导入与事件骨架

定位：账本（reference/05）定存储（统一事实信封），本件定**灌装策略**——导入期如何把静态完本全本喂进信封。真实写作路径（逐章即时增量）与修订路径不在本件范围；三条路径共用一个信封。

## 铁律（先决条件）

1. **粗层不产事实锚**——只有逐章精读可写账本事实（带 evidence）；粗层产物一律导生物，可焚可重建。依据：漏登记不可自愈。
2. **漏读必有台账**——覆盖率台账记区域状态机 `未读→粗扫→精读→已核销`，外加 `疑点(重开)`；未覆盖部分显式存在、可查询、可排期。
3. **事件=导生层**——包含树与指引链可焚可重建，节点带锚指向账本事实与章节区间；图永不为源。
4. **修复过闸**——精读升级后的核销需复核（邻域再抽一根，或确定性交叉验证）。

语料不进仓不分发（`.bench/` gitignored）。

## 金字塔分层（读取结构）

- **L0 确定性信号层（零 LLM）**：结构树卷边界、场景断裂、name-census 人物在场分布、字数/密度离群、伏笔嫌疑句式——产出候选边界与密度地图。确定性工具定骨架，LLM 只填语义。
- **L1 纲要层（便宜模型）**：卷摘要→弧线→事件骨架粗稿（自顶先验），几十次调用。
- **L2 事件平铺层**：簇内平铺挖事件，每事件 `{标题, 章节区间锚, 参与者, 一句话梗概}`。
- **L3 需求驱动精读层**：对每个事件过「信息需求清单」（在场人物状态/知情/设定规则/道具/未兑现承诺/因果桥）——缺什么读什么；复用产品工具链（search_content / read_chapter / ledger_slice），同一张清单导入期干跑、写作期实跑。
- 归并层：卷/弧摘要 reduce。

## 事件包含树与指引链

- **层级由包含关系推导，不由分档判定**：大/中/小仅作展示标签，机制消费**排序**（比较判断比绝对分档稳定，预算松紧自动伸缩）。
- **两方向对撞**：自顶（L1 纲要）× 自底（L2 平铺）互认领；认领不上即疑点、即反馈回路触发。
- **关系二分（防成环）**：**包含**（部分-整体，父区间罩住子区间——确定性可校验：区间覆盖/兄弟不重叠/无环/每章有归属路径）定义树与层级权重；**指引**（埋设-兑现/因果，天然跨时间）是横跨树的链，不定义层级，定义**承重系数**（被引用越多越承重）；指引链=账本 promises 维度的图形态。
- **注意力公式**：`层级权重（树位置）× 承重系数（链度数）× 检测器加成（反馈回路）`——三个来源、一张优先队列、一个预算。

## 反馈回路（质量控制）

- **快环（实例级）**四类检测器、确定性优先：①抽查差值（抽样深读发现账本外新事实，主通道）；②确定性异常（有 presence 无 event 的嫌疑空洞、密度离群、嫌疑句式落未精读区、同章同实体+颜色/数量词邻近共现的一致性检查——零成本常开，LLM 探针退居复核位）；③下游消费失败（彩排补不齐信息需求清单）；④对账命中（矛盾扫描开火=局部模型错误嫌疑）。
- **修复阶梯**：局部精读（默认）→邻域扩散→确定性补扫→挂账疑点进报告（预算不足时的正路：显式的未修复嫌疑好过静默声称覆盖）。
- **慢环（策略级）**：快环核销记录聚合漏检率（按检测器/卷/密度档），持续偏高调全局参数（簇粒度、抽查率、粗筛提示词）重跑受影响通道。
- **抽查分层抽样**：按卷、按密度档、按「离任何事件最长的未触及段」各设配额；抽查差值兼作需求驱动管线的召回率度量。
- **规约（与账本规范同源）**：账本锚为坐标权威（L2 区间锚与账本锚冲突以账本为准，冲突入快环）；名词候选未命中任何已知名/别名的标「超域疑似」入台账候选队列，不得静默丢弃。

## 成本与对照

- 均匀深读净本 1137 章 ≈2300 次深调用+矛盾窗口 ≈230 次；分层管线深调用砍约 70–80%（L1 几十+L2 150–300+L3 400–600+抽查 70+归并 50）。
- 精度论点：均匀抽付的失效模式是 over-extraction（噪音淹没信号）；需求驱动把钱花在「将被消费」的信息上，精读预算本身是精度仪器。
- **对照判据**：四项对比（密度与精度/事实召回/失控检出率/成本）由作者对照数字裁决；判据框架=召回损失与成本节省的交换比+失控实证检出率不降（失控实证目录实锤 4 条必须检出）；「维持均匀深读」保留为活候选——对照显示召回损失大于成本节省价值即退回。

## 技术路线（挂触发、不预建）

- embedding 语义索引：指引链跨章埋设-兑现匹配是正式触发场景（纯 LLM 配对平方级灾难→向量粗配+LLM 确认），本地模型零额度。
- RAPTOR 层次摘要树（章摘要结构天然是其骨架）、GraphRAG/Graphiti 仅导生层参照、Contextual Retrieval 为 embedding 启动时增强项、长上下文整本吞只作对照组变体。
- 明确不用：知识图谱作事实源、游戏式状态机。

## 已知不确定项（测量/试跑裁决）

包含树区间校验在多视角/闪回重灾区的失败率（失败率高则退化为「弧级为顶层」）；指引链召回未验证（靠抽查差值标定）；LLM 粗筛质量下限未测（L1/L2 可能需阶梯模型策略）；L3 事件间共享读段缓存粒度未设计；覆盖率台账落盘形态未定（倾向导生物目录）。
