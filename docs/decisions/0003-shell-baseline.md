## 布局基线

- 三栏：左结构树 260px / 中正文 720px 居中 / 右 AI 面板 360px，默认收起，`Ctrl+J` 呼出；
- `F8` 专注模式；打字机滚动锁 42%；明暗切换。

结构树：卷/章/场三级，带状态点（草稿/打磨/定稿）+ 字数。

## 安全阀四件（Day-1 必须有，否决级，沿用 novel-rl 教训）

1. 删除一律软删进 `.novel/trash/`，永不物理删除；
2. 保存显式报错（失败弹窗，不静默）；
3. 保存时滚动快照 `.novel/history/`（每章保留 N 份）；
4. 全稿导出 txt（最小投稿出口，复制出去格式直接用——章为最小结构）。

## AI 交互基线（第 3 周细化）

- 选区浮动条（框选即问，Codex 式）；
- AI 改写候选：内联删除线/侧栏 diff 二态；
- 暂存抽屉：AI 产出全部先进暂存区，**批量勾选**采纳/整改/丢弃（铁律，见 01-产品定义）；
- 两个讨论存区：无归属讨论 / 章节内讨论。
