# 0006 · 修复轮（周 2-3 审核后质量修复）

- 状态：已定稿（2026-08-09），修复轮动工
- 来源：周 2-3 独立审核列出的不足项（跨对话记忆缺失、shell store 无单测、rewrite 无输出护栏、updater 占位、自动保存缺失、魔法数散落、0004 挂账），本轮按批次 A–F 逐一处理。

## 决定

- **跨对话记忆 = 会话历史 messages 回放**（core `/chat`，替代单轮 `prompt: text`）：从最新往回取最近 20 条、合计 ≤25k 字符；工具调用结果不重放（AI SDK 要求 tool-call 与 tool-result 成对，历史只存 assistant 侧，回放会校验失败）；纯工具轮（空文本）跳过；相邻同 role 合并（AI SDK 实测不合并，部分 provider 拒绝连续同角色）；截断后首条 assistant 裁剪（无对应 user 引导）。实测脚本 `core/scripts/verify-memory.mjs`（真实 LLM 同会话两轮召回）。
- **shell 三个数据 store 补单测**（work / chat / candidates）：mock CoreClient 经既有 `init(client)` 注入，不引 mock 框架新依赖；work 为模块单例，测试 beforeEach 重置被引字段防泄漏。
- **rewrite 输出护栏**：绝对上限 20k 字符；结果/原文长度比须在 0.2~3 之间；违规发 SSE error（壳走失败红条），杜绝未完成改写或注水产物进暂存区。
- **自动保存 = 60s 低频兜底**：App 启动后每 60s 有脏改动才落盘（`saveCurrent` 自带 saving 互斥），失败走显式红条；**不设开关**（可配置默认否）。
- **search_content 口径定稿**（0004 挂账清除）：只搜正文——frontmatter 是结构元数据不参与搜索；命中行号按文件实际行号（含 fm 行）。
- **Editor 浮动条几何参数收进 `theme.ts` layout**（barH / 行间隙偏移 / 行高 / 贴边距），CSS 侧加同步注释："可配置默认否"落地为几何参数也进唯一偏好源。

## 明确不做（记档）

- **updater 保持占位**：端点指向 `http://127.0.0.1:9/...`，启动即后台检查、失败只记日志；本仓自用、无发布通道，对外分发时再接真实端点（README 已注明）。
- **丢弃候选不做 UI**：`discarded` 状态已落库可查，够用即止，不做回收站/恢复视图。
- **索引库 / 会话容量治理后置**：`.novel/` 已留口（0004），长会话截断由回放预算兜底，不做全文索引与历史归档。
- **自动保存不设开关**：60s 低频 + 显式红条足够，不做设置项。

## 落选

- 消息历史全量回放：token 随会话无限膨胀，必须设条数/字符预算截断；
- 重放工具调用链（含 tool-result）：存储无 tool-result 侧，AI SDK 成对校验必失败，且模型不需要重看工具返回；
- 会话按条数/天数自动归档压缩：当前单作者用量远未触及，复杂度不配收益。
