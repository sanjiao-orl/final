# 0007 · 协议契约 v1（/v1/ 版本化 + 进程握手 + event_pump）

- 状态：已定稿（2026-08-12），D 组工程通道先行落地（壳重做前提）
- 来源：`docs/壳重设计-设计需求.md` §三 D 组（D1/D2/D4 落地，D3 明确不做，见下）
- 范围：core ↔ 壳/外部客户端之间的 HTTP + SSE 契约。本文件是**唯一契约真相**；客户端只按本文件消费，不依赖引擎内部类型。

## 一、版本化规则（D1）

- 全部业务路由挂 `/v1/` 前缀；`protocol` 字段（整型，当前 `1`）与前缀同步递增。前缀变了 `protocol` 必变，反之亦然。
- 无 `/v1/` 前缀的旧路径一律 `404`，错误消息带迁移提示（`{ "error": "未找到: POST /chat（协议已版本化：请使用 /v1/ 前缀…）" }`）。
- `/v1/health` 响应 `{ ok, version, protocol }`——客户端的最小握手探针。
- 变更纪律：协议字段/事件顺序/错误形状的任何变更必须升 `protocol` 并更新本文件；兼容性由消费者按 `protocol` 校验（见 §三）。

## 二、端点契约

鉴权：除标注「免鉴权」外，一律 `Authorization: Bearer <token>`（token 来自 ready 行 / `core-runtime.local.json`，每次启动随机）。

### REST

| 方法 | 路径 | 鉴权 | 请求 | 成功响应 | 错误 |
| --- | --- | --- | --- | --- | --- |
| GET | `/v1/health` | 免 | — | 200 `{ ok, version, protocol }` | — |
| GET | `/v1/dev` | 免 | — | 200 HTML（内嵌联调页，token 内嵌于页面） | — |
| GET | `/v1/sessions[?scope=]` | Bearer | — | 200 `{ sessions: [{ id, title, scope, updatedAt }] }` | 400 scope 非法 |
| GET | `/v1/sessions/:id` | Bearer | — | 200 `{ sessionId, messages: [{ id, role, content, toolCalls, createdAt }] }` | 404 会话不存在 |
| POST | `/v1/tools/:name` | Bearer | 工具参数对象 | 200 工具结果（`structuredContent` 优先，JSON 文本解析回对象，非 JSON 原样） | 404 工具不可用/非法名；502 `isError` |
| POST | `/v1/candidates` | Bearer | `{ chapter, original, proposed, instruction?, sessionId? }` | 200 `{ candidate }` | 400 请求体不合法 |
| GET | `/v1/candidates[?status=&chapter=]` | Bearer | — | 200 `{ candidates }` | 400 status 非法 |
| PATCH | `/v1/candidates/:id` | Bearer | `{ status?, proposed?, instruction? }`（至少一项） | 200 `{ candidate }` | 400/404 |

### SSE（POST，响应 `text/event-stream`）

事件帧：`event: <name>\ndata: <JSON>\n\n`；流起始先发一行注释帧 `:ok`（防缓冲）。

**`POST /v1/chat`**（请求：`{ sessionId?, text, tier?, workDir?, scope? }`）

事件顺序：`text-delta` / `tool-call` / `tool-result` 可多次、任意交叠，**以 `done` 或 `error` 收尾（恒为最后一帧）**；`done` 后流关闭。

| 事件 | data | 说明 |
| --- | --- | --- |
| `text-delta` | `{ delta }` | 增量文本，客户端拼接 |
| `tool-call` | `{ id, name, args }` | 工具调用开始（多轮可多次） |
| `tool-result` | `{ id, name, result }` | 工具调用结果，与 tool-call 的 `id` 配对 |
| `done` | `{ sessionId, messageId }` | 流成功结束；assistant 消息已落库 |
| `error` | `{ message }` | 流失败结束（模型错误/护栏拒绝） |

校验失败（请求体非法 400、会话不存在 404）在进入 SSE 前以 JSON 错误返回。

**`POST /v1/rewrite`**（请求：`{ original, instruction }`，无工具、不落库）

事件顺序：`text-delta`（可多次）→ `done | error`。

| 事件 | data | 说明 |
| --- | --- | --- |
| `text-delta` | `{ delta }` | 增量文本 |
| `done` | `{ text }` | 完整改写文本（已 trim、过输出护栏） |
| `error` | `{ message }` | 流失败/护栏拒绝（超长/过短/注水/空结果） |

### 错误形状

- JSON 错误：`{ "error": string }`；SSE 流内错误：`error` 事件 `{ "message": string }`。
- 状态码语义：`400` 请求体不合法、`401` 未授权、`404` 不存在/旧路径、`413` 请求体过大、`502` 工具执行失败。

## 三、进程握手与版本校验（D2）

- core 启动后在 **stdout ready 行**（壳接线通道）与 **`core-runtime.local.json`**（外部消费者通道）自报同一组字段：

```json
{ "event": "ready", "port": 43210, "token": "…", "pid": 1234,
  "startedAt": "…", "version": "0.1.0", "commit": "abc1234", "protocol": 1 }
```

| 字段 | 含义 | 校验 |
| --- | --- | --- |
| `version` | core 包版本（`core/package.json`） | 展示用，不参与校验 |
| `commit` | git 短 commit；非 git 环境 `"unknown"` | 展示用，不参与校验 |
| `protocol` | 协议契约版本 | **硬校验**：消费者期望值不符即拒接（快速失败） |

- 壳侧校验（`shell/src-tauri`）：ready 行 `protocol` ≠ 期望值（当前 `1`）→ 标记 core 启动失败，不接线。
- **Node 版本门禁**：core 启动第一件事校验 `process.versions.node` 主版本 ≥ 24（根 `package.json` engines 对齐），不满足直接拒启。
- `core-runtime.local.json` 路径：默认仓库根，`CORE_RUNTIME_FILE` 可覆盖（`.gitignore` 的 `*.local` 已忽略）。

## 四、SSE 单一发射点（D4）

- 所有 SSE 帧**只经 `core/src/event-pump.ts` 的 `EventPump` 写出**（`http.ts` 不再提供裸帧写入）。
- 保证：帧写序 = 发射序（写队列串行，多生产者并发不交错）；泵可绑定会话 id（按会话保序）；`end()` 排在已入队帧之后，`done`/`error` 恒为最后一帧，之后不再接受新帧。
- handler（`chat.ts` / `rewrite.ts`）不得直接 `res.write` 帧；新增 SSE 端点必须走 EventPump。

## 五、明确不做（D3 记档）

- **依赖冻结契约文档不做**：`core/package.json` 锁版本即可（lockfile 在仓），不新增冻结基线/补丁表治理文档——踩「禁止新增治理文件」红线，单作者场景价值存疑。

## 落选

- 旧路径保留为 deprecated 别名：版本化意图就是让旧客户端快速失败（404 + 提示），别名只会掩盖脱节；
- 壳按 `version`/`commit` 精确匹配校验：单仓自产自销，版本号每次发布都变，精确匹配必误杀；`protocol` 才是兼容性边界。
