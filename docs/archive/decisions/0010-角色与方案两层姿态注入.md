# 0010 · 角色与方案（两层姿态注入）+ 注入面分层

> 2026-08-17。起因：批三-3 规划讨论中，作者提出提示词只开放模板级（类比编程助手的 coder/reviewer/researcher 角色），进而提出两层结构——角色自由组建（第一层）、角色组装为方案（第二层，每本书保存几套）——并要求借整体审视修订既有规划、核查功能/UI 重叠。经 core 注入面亲读 + 壳侧 UI 盘点取证定稿。

## 决策

1. **提示词切层**：封存层（输出契约/工作流指引/工具描述，永不开放，改坏即 502 或注入失效）vs 开放层（角色 = AI 的姿态与人格，改不坏机制，最坏是写得烂）。只开放角色层。
2. **两层结构**：
   - **角色库**:app 级预置（责编/毒舌书评人/小白读者/讨论陪练）+ 书级 `.novel/personas/*.md` 自由组建，同名遮蔽；md + frontmatter（name/description）,core `prompts.ts` 同构 scanSkills 扫描（书级扫描已有先例，不下放 domain），热重载。
   - **方案**：书级 `.novel/schemes/*.md`,frontmatter 写「通道 → 角色」映射（chat/rewrite/review），正文为备注不注入；每本书可存多套。
   - 方案 = 「角色 × 通道」分配表（同构于模型侧的预设 + 用途分配）;**不做多人格叠加进单通道**（同一通道 AI 不能既是责编又是毒舌读者，不自洽）。
3. **激活**:per-work 书级指针文件 `.novel/active-scheme`（单行文本 = 方案名），随书目录走（换机/重装壳不丢，作品自包含）。**读在 core**（清单端点返回 personas/schemes/激活名，读 .novel 已有先例）;**写走 domain 小工具**（原子写 + 校验方案名在清单内）——保住「core 不写书目录、领域文件归 domain」分工。
4. **注入**:chat/rewrite/review 三通道请求体各加可选 persona 字段；壳把激活方案解析成通道角色名带出，**core 只懂 persona 不懂方案**（职责最薄）；角色正文拼系统提示尾段「## 当前角色」；无指派 = 零注入（可配置默认否）。review 输出契约封存，角色只影响评判姿态；cold-read.md 的「付费读者+编辑耳朵」身份句降级为「默认角色」注释，被指派覆盖。
5. **注入面分层（先于叠加）**:`chat.ts` 系统提示的 string += 组装抽成显式分层——**契约层**（md 文件）→ **姿态层**（角色，默认无）→ **数据层**（声口摘要/账本切片，按 scope);review/rewrite 同口径。批三-3/3-4 的所有新注入都按此分层落位，防止叠加失控。
6. **壳**:Toolbar 右组「审批模式」pill 旁加方案 pill（`tb-mode` 形态 + `WorkMenu` 式下拉，两个先例拼装，零新形态）；恒可见（单栏制下 composer/会话栏落点分别被「窄化为 chat 专属」「藏进会话栏」否决）；无方案时显示「方案：默认」。角色/方案的壳内编辑 UI **缓做**（触发：改文件改烦；落点 SettingsColumn「作品目录」组后插「作品级设置」组）。
7. **质量闭环分层**：机械层（domain 确定性工具，无姿态基线）/ 方法层（skill，流程编排）/ 姿态层（角色方案）/ 数据层（账本/声口/issues)。**确定性检查不被方案配置、不被角色影响**——方案只绑定 LLM 通道姿态。
8. **批三-3 修订**:「细纲/讨论陪练」skill 候选**移除**（姿态不是方法论，转为角色预置）；章节起草 skill 保留候备但剥离（姿态归角色、声口归 style.md,skill 只留流程）；声口建档/chat 账本切片/上下文栏联动（含采纳后诊断自动重跑）不变。
9. **skill 准入规范**:description 必须触发条件式（何时用 + 何时不用/反向边界）；两条预置 skill（去AI味润色/章节体检）随批三-4 改写。

## 缓做（触发条件驱动）

- 角色/方案壳内编辑 UI（触发：改文件改烦）。
- 确定性治理可调化（触发：真实写作反复误报/漏报；预定方向：书级规则抑制阀 → 词表/阈值数据文件化 → 规则注册表重构）。
- skill 管理 UI（触发：skill 多到管不过来，沿用 0009)。

## 落选 / 不做

- 方案入口放 composer 或会话栏：前者把跨通道方案窄化为 chat 专属，后者被单栏制藏起（可见性归零）;Toolbar 恒可见且语义正。
- localStorage 激活记忆：换机/清缓存丢激活态；书级指针文件随书走。
- 多人格叠加进单通道：不自洽。
- 方案配置确定性检查项：机械层双写源，违反第 7 条边界。
- 开放输出契约/机制提示编辑：改坏机制，封存层不动摇。
