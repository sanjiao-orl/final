# 壳重设计:高保真原型设计说明(双审用)

- 日期:2026-08-10
- 性质:设计方交付说明,配套原型 `prototype/index.html`(单文件静态 HTML,可交互)
- 审阅方式:浏览器打开原型,右下角「演示」控制条切换全部状态;「设计标注」开关显示决策注释点
- 已验证:明 / 暗 / 审批卡 / 设置面板四态真实浏览器截图核验(`.shot-*.png` 留存于 prototype/);v2 改良后补 `.shot-v2-*.png` 六态(明/暗 × 收起/会话/工具)

---

## 一、产出形态(开放项 1 的提案)

**单文件静态 HTML,可交互状态演示,零依赖。**

理由:壳的争议点几乎全在交互(B1 浮层、B3 卡片、B6 审批、抽屉与面板的开合),静态图稿无法评审交互;单文件 HTML 双击即开、可截图、可直接当实现的视觉参照。CSS 变量与 `shell/src/theme.ts` 严格同名同值,实现期可直接搬运。

## 二、视觉系统(延续,不新增)

- 色板:纸色 `#FAF7F0` / `#26241F`、panel、ink、muted、line、accent `#6B4EFF`、ok、danger、三档状态点,全部沿用 theme.ts;**未新造主色**
- 派生语义色(建议色底、选区高亮、删除线色、警示底)一律 `color-mix` 由主 tokens 同温同饱和派生,实现期同样可推导
- 排版:正文思源宋体 17px / 行高 1.75 / 段首缩进 2em / 行长 ≤38 字(720px 列);UI 用系统黑体,禁等宽;章题加字距 0.14em 立仪式感
- 材质:纸感靠**细发线(1px hairline)与留白**,不贴纹理图;阴影只给浮层/模态两档,平面元素一律发线分隔
- 动效:抽屉/面板开合 0.42s cubic-bezier(0.4,0,0.2,1);hover 0.15s;AI 调用中脉冲点 1.5s;`prefers-reduced-motion` 全量降级;6px 细滚动条

## 三、布局决策

三栏骨架不变(树 260 / 编辑器居中 / AI 360,顶栏 42px),暂存抽屉 ≤40% 高——与现状一致,重做的是能力密度而非骨架。理由:作者肌肉记忆已在现状骨架上形成,且对标(Scrivener binder / NovelCrafter / kimi-code-desktop)均为三栏;骨架翻新无收益、有迁移成本。

### 开放项 3 · 交互细节提案(原型已定形,确认即冻结)

- 候选浮层:580px 宽、候选 tab + 纵向卡列表、选中卡 accent 左缘、底部打磨输入框常驻;Esc/点击外部关闭;垂直位置钳位在暂存抽屉之上
- 工具卡:默认折叠(头行一行),进行中/挂起自动展开;挂起卡在 ask 模式下内嵌「查看审批卡/拒绝」
- 审批卡:480px 居中模态,遮罩点击不关闭(危险操作必须显式选择);三档按钮固定顺序 拒绝/允许一次/允许本会话
- 暂存条:原文/候选双栏对照 + 3 行截断;采纳后 toast 4.5s 自动消隐,还原入口不随 toast 消失(顶栏快照常驻)
- 树:拖拽把手 hover 才显,落点用 2px 指示条而非位移挤压(避免重排抖动);场大纲继承章的激活态

### 开放项 4 · 壳组件/目录结构建议(供实现方参考,不约束)

```
shell/src/
  components/
    Toolbar.svelte            # 顶栏 + ask 模式指示
    tree/TreeView.svelte      # 卷章场三级 + 搜索 + 拖拽(A3/B9)
    tree/DragReorder.ts       # 卷内重排事务(批量改名前缀 + title 同步)
    editor/Editor.svelte      # TipTap + 打字机 + 场跳转
    editor/SelectionPopover.svelte  # B1 多候选浮层 + 打磨输入框
    editor/suggest.ts         # 内联装饰(沿用现状)
    staging/StagingDrawer.svelte    # 暂存抽屉 + 快照提示(B4/B8)
    ai/AiPanel.svelte         # 会话管理(B7)+ 消息流
    ai/ToolCard.svelte        # B3 工具卡(折叠/展开/挂起)
    approval/ApprovalCard.svelte    # B6 审批卡(ask/auto/yolo)
    settings/SettingsPanel.svelte   # 设置面板
  lib/
    theme.ts    # tokens 唯一来源(不移除,设置面板写回 CSS 变量)
    core.ts     # /v1/ 版本化客户端(D1)
    approval.ts # 审批模式状态机(壳承担,B6)
    snapshot.ts # 采纳前快照 + 还原(B4)
```

原则:交互产品逻辑(会话/拖拽/裁决/审批)收在壳,`approval.ts`/`snapshot.ts` 为壳私有;core 只消费版本化契约。

## 七、v2 变更(2026-08-12,作者实测反馈后改良)

- **背景**:右侧固定 360px AI 面板把挂载/操作、工具卡、消息流、composer 堆在一栏,既挡正文又密集难操作——v1 实测最大问题。
- **改良**:默认收成 48px 图标窄条(会话/工具/设置三入口,hover 提示 + 激活态),正文默认全宽;点击图标展开 360px 面板,会话与工具拆成两个互斥视图(工具卡从消息流中移出,不再堆叠);设置沿用右滑面板,不重复造。
- **交互**:展开/收起 0.42s 动效;Esc、点击正文外部、再点当前视图图标均可收起;Ctrl+J / 顶栏 AI 按钮切换展开;专注模式(F8)连窄条一起隐藏。
- **能力全保留**:B7 会话(挂载 chips/搜索/归档/重命名)、B3/B10 工具卡(折叠/展开就地审阅)、B6 审批卡(工具视图内「查看审批卡」入口)、composer、暂存抽屉联动(B4/B8)、明暗切换。
- **截图留存**:`prototype/.shot-v2-*.png` 六张(明/暗 × 收起/会话/工具)。
- 版本关系:v1(commit 2c33b7d,固定 360px 面板)已被 v2 原位替换,本文件其余章节仍按 v1 描述,以本节为最新口径。
