## 产品

网文连载单作者本地 AI 写作工作台（小说领域的 Cursor):Windows 桌面、纯本地、无账号、BYOK 双模型。需求基线 `01-产品定义.md`（原则：人的方向 AI 的笔 / 结构即智能 / 可配置默认否）。

验收口径：以作者真实写作为唯一验收（作者已用本软件持续写作多章；原北极星「写完 3 章可投稿水准章节」已达成，2026-08-16 起移除）。止损线：长期无动力用它写完一章，判定假设不成立，体面终止（可剥离资产：账本/core sidecar/领域工具）。

## 架构

`core/`(Node sidecar:AI SDK v7 + MCP client + node:sqlite 会话 + 127.0.0.1 HTTP/SSE)+ `domain/`(MCP stdio 领域服务，26 工具）+ `shell/`(Tauri 2 + Svelte 5 + TipTap,v5 五栏 + 作者笔记）。提示词与 skill 统一 md 文件机制（解析序 NOVEL_PROMPT_DIR > 随包释放目录，dev 直读 `core/prompts/`;mtime 热重载，改文件即生效；决策 0008)。决策记录 `decisions/`（速查见文末）。
