# Issues Log — The Cold Read (append-only)

> 一行一条,固定格式,只追加不改删;修复或推翻时另起一行注明。本文件最后约 40 行是每次坐下续读的恢复上下文之一,格式必须保持精确。

Format: `CR-### | ch:line | SEV | CAT | "quote" | why / reader-moment | fix direction | LINE/SCENE/STRUCT/META`
SEV: BLOCKER / MAJOR / MODERATE / MINOR。CAT: CONT, CANON, VOICE, CRAFT, STRUCT, PACE, REPEAT, META。

## Legend

| Severity | Meaning |
|---|---|
| **BLOCKER** | 破坏对文本的信任:当场矛盾、时间线不可能、重复/粘贴句、凭空知情、物件/名字/事实出错 |
| **MAJOR** | 硬绊脚——重读或略读:出戏对白、说明倾倒、无铺垫揭示、已登记事实重复解释、泄底 |
| **MODERATE** | 注意到、原谅一次、不原谅三次:重复场景形/意象(记次数)、节奏塌陷、套路开头、铺垫词簇 |
| **MINOR** | 打磨:词癖、元数据错误 |

| Category | Meaning |
|---|---|
| `CONT` | 连续性——与更早的页面、账本或自身矛盾 |
| `CANON` | 与锁定设定或素材冲突 |
| `VOICE` | 角色或叙述者口吻破裂 |
| `CRAFT` | show-then-tell 族:解释意象、点名情绪、直说主题 |
| `STRUCT` | 章节/arc 架构:节拍重复、场景错位、接缝失败 |
| `PACE` | 塌陷、赶工、过度延展 |
| `REPEAT` | 重复意象、短语、场景形——必记次数 |
| `META` | 文件、标题、编号、前注——非正文 |

末字段 = 修复范围:`LINE`(一句)/ `SCENE`(一场)/ `STRUCT`(跨章)/ `META`(文件/元数据)。
